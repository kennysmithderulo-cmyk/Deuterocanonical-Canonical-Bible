# Study Bible

"Study the Word. Teach with Confidence."

A professional, production-ready Bible study PWA for pastors and serious readers. Built with Next.js (App Router), TypeScript, Tailwind CSS, Supabase (Auth + Postgres), and designed for Vercel deployment.

## Status

- ✅ Phase 1: Next.js + TS + Tailwind + Supabase + Auth + base UI
- ✅ Phase 2: Bible + Apocrypha schema, seed metadata, Bible reader skeleton
- ✅ Phase 3: Apocrypha import UI + reader, cross-ref component, import API pattern
- ✅ Phase 4: Enhanced Bible reader + study panel, lexicon viewer foundation

## Tech Stack

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS + shadcn/ui (foundation)
- Supabase (Auth + Postgres)
- Zod (validation)
- PWA (next-pwa + workbox)
- Vitest (testing)
